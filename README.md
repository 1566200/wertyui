# 环境学概论 · 背诵卡（加密版）

这是**加了密码**的版本：站点里只有密文，打开网页必须先输密码，输错看不到任何题目和答案。
可以直接上传到 GitHub Pages，公开仓库、公开网址都没关系——别人拿到网址也只是一把锁。

> **密码不要写在这个文件里，也不要提交到仓库**。密码只有你自己知道（见聊天记录 / 你另存的备忘录）。

---

## 一、先做一件必须做的事：删掉旧仓库

旧的 `zhuanye` 仓库里有两样东西让我不能只让你“覆盖上传”：

1. `cards.js`、`print.html`、`环境学概论背诵卡-离线单文件.html` 都是**明文答案**；
2. Git 历史里还留着这些明文，以及**你的邮箱（含手机号）**，任何人翻提交记录都能看到。

**只覆盖文件没用，历史照样能翻出来。** 所以：

> 仓库 → **Settings** → 拉到最底部 **Danger Zone** → **Delete this repository** → 按提示输入仓库名确认。

如果你还想保留旧内容做备份，先把整个仓库 Download ZIP 存到本地，再删。

## 二、上传新仓库（和之前一样，3 步）

1. github.com/new → 仓库名随意（例如 `zhuanye`）→ 选 **Public** → Create。
2. **uploading an existing file** → 把**本文件夹里的 12 个文件**全部拖进去（含隐藏文件 `.nojekyll`；没有 `cards.js`、没有 `print.html`，这是对的）→ Commit。
3. **Settings → Pages → Deploy from a branch → main / (root) → Save**，等 1—2 分钟。

网址还是 `https://你的用户名.github.io/仓库名/`。

## 三、手机上

1. 打开网址 → 输入你设置的密码；
2. 勾选 **本机记住 30 天**（这台设备这一个月不用再输）；
3. Safari「分享 → 添加到主屏幕」/ Chrome「安装应用」，之后像 App 一样打开，**断网也能背**（内容已在本机，解密也在本机）。

## 四、换密码

1. 打开 `环境学概论背诵卡-加密码工具\设置密码.html`（本地双击，**不要上传**）；
2. 选择本地的 `cards.js`（在旧的 `环境学概论背诵卡-github` 文件夹里）；
3. 输入新密码两次 → 点「生成 secure-data.js」，会下载一个新文件；
4. 用它覆盖站点文件夹里的 `secure-data.js`；
5. 把 `sw.js` 第 3 行 `VERSION` 改成新值（如 `env-cards-lock-v2`）；
6. 两个文件上传覆盖 → 手机上重新输一次新密码。

> 换密码后，手机里“记住 30 天”的旧钥匙自动失效（解密失败会自行清除），需要重新输入。

## 五、这个密码到底有多安全

- 用的是 **PBKDF2-SHA256（21 万次迭代）+ AES-256-GCM**，密钥不落在服务器，也不上传；
- 公开的只有：页面外壳、样式、图标、加密后的密文；
- 能防住：拿到网址的人、翻你仓库源码的人、搜索引擎；
- 防不住：知道你密码的人、拿到你已解锁手机的人；
- 因为密文是公开可下载的，**弱密码存在离线暴力破解的可能**——别用生日、学号、手机号，建议 12 位以上、字母数字混排。

## 六、文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 锁屏 + 卡片页面 |
| `secure-data.js` | **加密后的题库**（唯一含答案的文件，密文） |
| `app.js` | 解锁逻辑 + 卡片交互 |
| `styles.css` | 样式（含锁屏与手机适配） |
| `sw.js` | 离线缓存（换密码/换题要改 VERSION） |
| `manifest.webmanifest` | 添加到主屏幕的名称与图标 |
| `icon-*.png`、`apple-touch-icon.png`、`favicon-32.png` | 图标 |
| `.nojekyll` | 不做 Jekyll 处理 |

## 七、以后改题目

题库现在是密文，**不能直接改 `secure-data.js`**。流程是：

1. 改本地的 `cards.js`（明文，只存在你自己电脑上）；
2. 用 `设置密码.html` 重新生成 `secure-data.js`；
3. 上传覆盖 + 改 `sw.js` 版本号。

这样明文永远不进仓库，密码也一直有效。
